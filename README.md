# Pure Live

**基于 Flutter 的开源多平台直播聚合播放器**

A third-party live stream aggregator built with Flutter.

> **Pure Live** 是一款开源的第三方多平台直播聚合播放器，使用 Flutter 构建，支持 Android、Windows、Linux、macOS 和 iOS。
